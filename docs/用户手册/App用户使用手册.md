# App 用户使用手册

App 用户使用本人手机号和一次性验证码登录，预约物资并在有效期内到柜领取。

## 第一次使用

首次使用前，请联系当前实例管理员完成资料建档、审核和启用。人工验证码模式不会发送短信，也不会自动创建账号。

![App 身份识别页](../assets/app-public-login-390x844-20260729.png)

## 使用一次性验证码登录

1. 打开 [移动端](https://vending.5gogogo.top/mobile/)。
2. 输入本人手机号。
3. 输入管理员交付的 6 位一次性验证码。
4. 阅读页面提示并勾选免责声明。
5. 选择登录。

验证码使用一次后立即失效。过期、撤销或输错达到上限时，请联系管理员重新签发。

![App 人工验证码登录页](../assets/app-public-manual-login-390x844-20260729.png)

## 预约物资

1. 在首页查看当天是否开放领取。
2. 选择在线柜机和可预约物资。
3. 选择数量，核对柜机、物资和保留时间。
4. 提交预约。
5. 在“当前预约”确认状态。

没有在线柜机、没有可用库存或不在开放时段时，页面不会提供可提交的预约。预约取货不要求付款。

## 到柜领取

1. 在预约有效期内到达页面显示的柜机。
2. 打开“当前预约”，再次核对柜机和物资。
3. 按页面提示完成距离确认和开柜确认。
4. 取出物资并关好柜门。
5. 等待页面显示最终结果。

页面尚未确认结果时不要重复开柜。保留当前页面并联系实例管理员。
