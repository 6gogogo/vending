# 补货员使用手册

补货员只处理分配给自己的柜机，并记录现场补货和巡检情况。

## 登录和确认柜机

1. 打开 [电脑后台](https://vending.5gogogo.top/login)。
2. 输入实例管理员开通的补货员账号和密码。
3. 登录后确认身份显示为“补货员”。
4. 打开“柜机监控”，确认目标柜机在列表中。

![电脑后台登录页](../assets/backoffice-login-public-1280x720-20260729.png)

## 补货和巡检

1. 进入目标柜机详情，核对柜机编号、货门和当前库存。
2. 按现场安排完成补货或巡检。
3. 记录异常柜门、库存差异和现场情况。
4. 将结果交给实例管理员登记或复核。

看不到未分配柜机属于正常权限限制。不要借用他人账号，也不要处理页面没有授权的柜机。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 目标柜机不在列表 | 请管理员检查柜机分配。 |
| 柜机离线 | 不要反复操作，记录柜机编号并联系管理员。 |
| 货门或库存异常 | 保留现场信息，停止继续补货并联系管理员。 |
| 忘记密码 | 从登录页进入“忘记密码”，或联系实例管理员重置。 |
