# 商户使用手册

商户使用电脑后台查看自己的补货货品、入柜记录和已分配柜机。

## 登录和核对身份

1. 打开 [电脑后台](https://vending.5gogogo.top/login)。
2. 输入实例管理员开通的商户账号和密码。
3. 登录后确认身份显示为“商家”。
4. 看不到商家工作台时，请实例管理员检查账号角色。

![电脑后台登录页](../assets/backoffice-login-public-1280x720-20260729.png)

## 查看补货信息

1. 打开“商家工作台”。
2. 查看可补货货品模板、数量和本人最近入柜记录。
3. 打开“柜机监控”，核对分配给自己的柜机。
4. 进入柜机详情，查看柜机状态、货门和可见库存。
5. 现场工作完成后，按当前实例的流程交由管理员登记或复核。

页面没有显示的人员管理、实例设置、远程开门和完整日志由实例管理员处理。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 看不到柜机 | 请管理员检查账号状态和柜机分配。 |
| 没有可补货模板 | 请管理员检查货品模板是否启用。 |
| 库存与现场不一致 | 记录柜机、货门和差异数量，交由管理员复核。 |
| 忘记密码 | 从登录页进入“忘记密码”，或联系实例管理员重置。 |
