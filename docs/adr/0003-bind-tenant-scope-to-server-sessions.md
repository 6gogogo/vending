# ADR-0003 将客户实例范围绑定到服务端会话

## 状态

已接受

## 背景

服务提供商需要先在平台范围创建和选择客户实例，再进入实例完成首管理员、角色、柜机和授权配置。若后台接口信任客户端提交的 `tenantId`，同一账号可能通过篡改请求读取或修改其他实例数据；若服务提供商全局会话直接兼具实例权限，也难以区分平台动作与实例动作。

当前仍使用 ADR-0001 的内存仓储和本地持久化文件，因此需要在不引入最终数据库模型的前提下，先建立可验证的租户边界。

## 决策

- 服务提供商全局会话只拥有平台概览、实例列表和实例开通权限。
- 进入客户实例时，服务端撤销当前令牌并签发绑定目标 `tenantId` 的新会话；退出实例时再次轮换为平台范围会话。
- 实例管理员、商户和补货员的租户范围由后台凭据和服务端会话共同确定，不接受业务请求体中的租户声明。
- 移动端公开注册、资料续填和登录使用受信反向代理还原的请求域名匹配已登记实例地址；本地非生产回环地址只映射默认模拟实例，不接受请求体或查询参数自报 `tenantId`。实例域名必须唯一。
- 用户、后台凭据、柜机、注册审核、开柜事件、柜机回调摘要、库存流水、操作日志和商户私有模板按会话中的 `tenantId` 过滤，并在读取、修改、撤销和外部柜机调用前拒绝跨租户对象；无法从柜机或事件可靠归属实例的回调摘要不向租户会话展示。
- 非默认实例只能访问显式标记为租户安全的后台路由；未完成租户化的旧模块保持关闭式拒绝。
- 客户实例、首管理员人员记录和首管理员后台凭据在同一持久化边界内创建，失败时回滚全部内存副作用。

## 影响

- 服务提供商必须显式“进入实例”后才能执行实例业务，平台范围不再展示跨实例业务明细入口。
- 令牌轮换使旧范围会话立即失效，降低浏览器保留旧权限上下文的风险。
- 同一域名不能开通多个客户实例；公开入口域名未登记、重复或实例已暂停时关闭式拒绝注册与登录。
- 商户和补货员的柜机分配成为列表、详情和开柜预检的共同授权依据。
- 新实例初期开放人员、注册审核、后台账号、柜机和人工验证码等已租户化能力；规则、预约等旧模块需逐一迁移后才能开放。
- SmartVM 货品查询只返回本次远端观测，不以 `devices:view` 权限改写全局货品目录或柜机本地配置。
- 当前单进程内存仓储只能提供进程内原子性；扩展为多 API 实例前，需要把会话、验证码消费和实例开通迁移到共享事务或 CAS。

## 后续

- 每迁移一个后台模块，都要补充跨租户读取、写入和外部副作用为零的回归测试，再标记为租户安全路由。
- 引入正式数据库时，把实例开通、后台凭据和人员创建放入同一数据库事务。
- 多进程部署前，将会话轮换、人工验证码单次消费和失败计数迁移到共享存储的原子操作。
