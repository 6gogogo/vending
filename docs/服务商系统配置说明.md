# 公益智助柜服务商系统配置说明

本文档供服务商维护人员使用，说明后台“系统设置”与受控部署配置中的全部字段。它不是实例管理员、商户、补货员或 App 用户的使用手册，不应向下级账号公开密钥、运行路径、供应商账号或平台维护方式。

文档只记录字段用途和操作边界，不记录任何实际密钥、密码、手机号或当前生产值。

## 一、先区分三个概念

| 概念 | 含义 | 可否在实例设置中随意切换 |
| --- | --- | --- |
| 服务商平台身份 | 服务商登录后的平台级运营身份，始终是正式服务商平台 | 不可切换为模拟身份 |
| 实例服务类型 | 创建客户实例时选择“正式服务”或“模拟服务” | 创建时确定；变更必须走实例开通流程 |
| 运行数据平面 | 当前 API 进程实际承载模拟数据还是实机数据，即 `simulation` 或 `live` | 不可在线切换，必须停服、备份并通过发布流程处理 |

正式实例只有运行在 `live` 数据平面并通过生产就绪检查后，才算正式运行。`mock`、后台签发人工验证码和阿里云 PNVS 是具体模块的实现方式，不是第三种实例服务类型。

## 二、账号可见范围

| 账号 | 系统设置 | 手册范围 |
| --- | --- | --- |
| 服务商 | 进入实例后可查看与当前数据平面相关的完整配置；敏感值默认隐藏 | 服务商、实例管理员、商户、补货员、App 用户 |
| 实例管理员 | 只查看和维护预约取货、领取差异额度等日常实例设置 | 实例管理员、商户、补货员、App 用户 |
| 商户 | 不显示系统设置 | 商户、补货员、App 用户 |
| 补货员 | 不显示系统设置 | 补货员、App 用户 |
| App 用户 | 不进入电脑后台 | 只查看移动端用户指引 |

任何下级账号都不能看到上级账号的维护入口、密码恢复方式、外部服务密钥或运行路径。服务端会再次执行同一权限检查，不能通过直接请求接口绕过页面限制。

## 三、设置页面状态说明

- “已同步”表示当前页面没有未保存改动。
- “N 项未保存”表示本页表单值已变化，但尚未写入受控配置。
- “未配置”表示该字段只有示例占位值，当前配置和运行环境均未提供实际值。
- “保存即生效”表示保存后当前进程会立即采用新值。
- “重启后生效”表示保存后还要由服务商重启当前实例 API。
- “由发布流程管理”表示该字段仅供核对，不能在运行中的正式实例直接修改。
- 敏感字段只显示掩码。留空或未重新输入时，不代表生产密钥已被删除。

正式实机实例不会显示任何仅限仿真或本机联调的字段。

系统设置按单项变更保存：页面只提交实际修改的字段，服务端也只原子更新这些字段。`.env.example` 只提供字段目录、控件类型和输入示例，不会作为实际配置写入受控 `.env`；未改动的注释、部署项和敏感配置保持原样。使用 `VM_DATA_ROOT` 时，`API_DATA_FILE`、`UPLOAD_DIR`、`SYSTEM_LOG_FILE`、`API_BACKUP_DIR` 和 `FINANCIAL_SINGLE_WRITER_LEASE_FILE` 均由统一数据根派生，页面不会再显示这些互斥的旧路径配置。

## 四、服务基础配置

| 配置键 | 作用 | 使用与修改边界 |
| --- | --- | --- |
| `NODE_ENV` | 决定 Node/Nest 的运行环境和生产安全门禁 | 正式环境必须为 `production`；由发布流程管理，重启生效 |
| `APP_ENV` | 应用侧运行环境标识 | 正式环境与 `NODE_ENV` 保持一致；由发布流程管理，重启生效 |
| `VM_DATA_PLANE` | 指定模拟数据平面或实机数据平面 | 正式实例为 `live`；禁止在线切换 |
| `VM_DATA_ROOT` | 统一派生账本、审计、上传、备份和租约路径的根目录 | 由部署方案固定；禁止在线修改或与其他平面复用 |
| `VM_DATA_PLANE_ID` | 当前数据平面的稳定唯一标识 | 用于阻止跨实例备份恢复；由部署系统固定 |
| `VM_SIMULATION_PROFILE` | 在模拟平面选择标准模拟或全真模拟 | 仅模拟平面显示；正式实机实例隐藏 |
| `VM_FULL_SIMULATION_ENABLED` | 对全真模拟执行第二道显式确认 | 仅隔离模拟环境使用；必须配合独立数据根和标识 |
| `VM_FULL_SIMULATION_SMARTVM_MODE` | 全真模拟中选择模拟柜机或真实 SmartVM | 仅模拟平面显示 |
| `VM_FULL_SIMULATION_PAYMENT_MODE` | 全真模拟中选择模拟支付或真实支付 | 仅模拟平面且关闭预约制时显示 |
| `VM_FULL_SIMULATION_VERIFICATION_MODE` | 全真模拟中选择 mock、真实短信或人工码 | 仅模拟平面显示；正式实例改用 `VERIFICATION_CODE_PROVIDER` |
| `VM_FULL_SIMULATION_AI_MODE` | 全真模拟中选择本地兜底 AI 或真实大模型 | 仅模拟平面显示 |
| `VM_FULL_SIMULATION_MAP_MODE` | 全真模拟中选择手工坐标或真实高德地图 | 仅模拟平面显示 |
| `VM_RESERVATION_ONLY_PICKUP` | 开启后必须先预约再取货，新的领取流程不创建支付单 | 实例管理员可维护；切换后重启生效 |
| `PORT` | API 进程监听端口 | 必须与同机反向代理一致；改动会影响入口，重启生效 |
| `API_HOST` | API 绑定的本机地址 | 生产通常为回环地址；由发布流程管理，不能改成公网监听 |
| `TRUST_PROXY_HOPS` | 指定可信反向代理的固定层数 | 仅在前方确有受信代理时填写；必须与实际链路一致 |
| `PUBLIC_BASE_URL` | 后端对外公开根地址 | 用于回调和生成外部地址；生产使用 HTTPS |
| `CORS_ORIGINS` | 允许浏览器调用 API 的来源白名单 | 逐个填写完整 HTTPS 来源，不支持通配符 |
| `API_DATA_FILE` | 旧式单文件 JSON 账本路径 | 标准模拟兼容项；使用 `VM_DATA_ROOT` 时不单独配置 |
| `UPLOAD_DIR` | 图片等上传文件目录 | 与数据、审计和备份目录隔离；由发布流程管理 |
| `SYSTEM_LOG_FILE` | 系统级安全审计日志文件 | 不得与业务账本共用；只能在停服维护窗口修改 |
| `API_BACKUP_DIR` | 账本、审计和上传清单的备份目录 | 与运行数据和上传目录隔离；由发布流程管理 |
| `ENABLE_LOCAL_MOCK_DEVICE_API` | 开启本机模拟柜机接口 | 仅回环模拟联调使用；正式实机隐藏并强制关闭 |
| `ENABLE_TEST_DEVICE_BOOTSTRAP` | 自动补入固定测试柜机数据 | 仅隔离测试使用；不得接触日常或生产数据 |
| `DATABASE_URL` | PostgreSQL/Prisma 连接串 | 当前 JSON 账本不会因填写此项自动切库；属于敏感项，切库需单独迁移 |
| `WEB_CONCURRENCY` | Web 工作者数量 | JSON 账本阶段固定为 1，重启生效 |
| `API_INSTANCE_COUNT` | 同一账本的 API 实例数量 | 当前固定为 1，禁止多个进程并行写同一账本 |
| `NODE_APP_INSTANCE` | 进程管理器实例编号 | 当前只能留空或使用单实例编号 0 |
| `BUSINESS_TIMEZONE_OFFSET_HOURS` | 业务日期相对 UTC 的小时偏移 | 中国大陆通常为 8；影响日期和额度统计 |
| `BUSINESS_DAY_START_HOUR` | 业务日切换的本地小时 | 例如 4 表示凌晨四点切换新业务日 |

## 五、地图服务

| 配置键 | 作用 | 使用与修改边界 |
| --- | --- | --- |
| `AMAP_WEB_KEY` | 后台与移动端加载高德地图的 Web Key | 正式地图服务必填；属于敏感配置 |
| `AMAP_SECURITY_JS_CODE` | 高德 JS API 安全密钥 | 必须与 Web Key 配套；属于敏感配置 |

缺少任一项时，正式地图模式不会降级为伪造地图；生产门禁会拒绝不完整配置。

## 六、大模型服务

| 配置键 | 作用 | 使用与修改边界 |
| --- | --- | --- |
| `OPENAI_API_KEY` | OpenAI 兼容接口的访问密钥 | 敏感项；只由服务商或密钥管理器维护 |
| `OPENAI_BASE_URL` | OpenAI 兼容接口根地址 | 默认只允许 HTTPS 公网地址 |
| `OPENAI_BASE_URL_EXACT_HOST_ALLOWLIST` | 允许访问的本地或私网模型精确主机清单 | 仅逐个填写主机名或 IP，不允许通配符 |
| `OPENAI_MODEL` | AI 工作台调用的模型名称 | 必须与供应商实际开放的模型标识完全一致 |
| `OPENAI_TIMEOUT_MS` | 单次大模型请求最长等待毫秒数 | 过小会频繁超时，过大则延长后台等待时间 |

未配置大模型服务时，AI 工作台应明确显示服务未就绪，不能把模拟回答伪装成正式外部结果。

## 七、柜机平台接入

| 配置键 | 作用 | 使用与修改边界 |
| --- | --- | --- |
| `SMARTVM_MODE` | 指定尚未接柜或使用正式 SmartVM | 新实例无柜机时选 `disabled`；录入首柜前切换 `real` |
| `SMARTVM_BASE_URL` | SmartVM API 根地址 | 正式接入时填写供应商生产 HTTPS 地址 |
| `SMARTVM_TIMEOUT_MS` | 柜机查询、开门和回写的最长等待毫秒数 | 超时后结果可能处于待确认，不能自动重试开门 |
| `SMARTVM_STATUS_STALE_AFTER_MS` | 柜机状态超过多久视为过期 | 过期状态会关闭式阻止开门 |
| `SMARTVM_OPEN_COMMAND_LEASE_MS` | 同一柜门开门命令的在途保护时间 | 防止网络未知时重复下发开门指令 |
| `SMARTVM_ALLOWED_NOTIFY_ORIGINS` | 额外允许的付款回写来源 | 多个 HTTPS 来源用英文逗号分隔 |
| `SMARTVM_CLIENT_ID` | SmartVM 分配的接入账号 | 敏感项，只由服务商维护 |
| `SMARTVM_KEY` | SmartVM 请求与回调签名密钥 | 高敏感项，不得写入文档、日志或聊天 |
| `SMARTVM_ALLOW_UNSIGNED_CALLBACKS` | 是否接受未签名回调 | 仅本机模拟联调使用；正式实机隐藏并强制关闭 |
| `SMARTVM_DEFAULT_PAY_STYLE` | 下发开门命令时的默认 `payStyle` | 由 SmartVM 合同确定；预约公益流程通常保持既定值 |
| `SMARTVM_AUTO_FORWARD_SETTLEMENT_PAYMENT_SUCCESS` | 结算后是否自动向柜机转发支付成功 | 预约制通常关闭；开启前必须完成真实支付闭环 |
| `SMARTVM_TEST_DEVICE_CODE` | 沙箱脚本默认测试柜机编号 | 仅模拟平面显示，不代表真实柜机已录入 |
| `SMARTVM_TEST_DOOR_NUM` | 沙箱脚本默认测试柜门号 | 仅模拟平面显示 |
| `SMARTVM_DOOR_STATUS_CALLBACK_PATH` | 接收柜门状态回调的路径 | 必须与 SmartVM 控制台登记路径一致 |
| `SMARTVM_SETTLEMENT_CALLBACK_PATH` | 接收结算回调的路径 | 处理实际取放货结果 |
| `SMARTVM_ADJUSTMENT_CALLBACK_PATH` | 接收补扣/差异回调的路径 | 预约公益流程只记录差异，不向用户自动补扣 |
| `SMARTVM_ADJUSTMENT_QUOTA_TIME_MODE` | 决定领取差异计入哪一天的额度 | 实例管理员可维护；通常保留 `auto` |
| `SMARTVM_REFUND_CALLBACK_PATH` | 接收历史退款结果的路径 | 仅用于历史支付兼容和恢复 |
| `SMARTVM_PAYMENT_SUCCESS_PATH` | 向 SmartVM 转发支付成功的接口路径 | 预约制不使用新的支付转发 |
| `SMARTVM_CALLBACK_MAX_AGE_SECONDS` | 回调时间戳允许的最大历史秒数 | 超过后按重放请求拒绝 |
| `SMARTVM_CALLBACK_FUTURE_TOLERANCE_SECONDS` | 回调时间戳允许领先服务器的秒数 | 只用于容忍小幅时钟误差 |
| `SMARTVM_CALLBACK_EVENT_MAX_AGE_SECONDS` | 回调可关联柜机事件的最长时间 | 防止旧回调误更新后续事件 |

## 八、支付服务

预约取货开启时，新的领取流程不需要支付配置，后台会收起支付分组。历史订单、退款和审计记录仍保留。

| 配置键 | 作用 | 使用与修改边界 |
| --- | --- | --- |
| `PAYMENT_MODE` | 选择关闭、自动、模拟或严格真实支付 | 正式实机只允许预约制 `disabled` 或严格真实 `real` |
| `PAYMENT_PROVIDER_TIMEOUT_MS` | 支付渠道外呼最长等待毫秒数 | 超时结果进入待确认，不应直接显示失败或重复扣款 |
| `PAYMENT_MOCK_ENABLED` | 兼容旧版模拟支付开关 | 仅模拟平面显示；新配置以 `PAYMENT_MODE` 为准 |
| `FINANCIAL_SINGLE_WRITER_ENABLED` | 启用金融账本单写者门禁 | 正式 JSON 账本必须开启 |
| `FINANCIAL_INSTANCE_ID` | 金融单写者实例标识 | 留空可自动生成；多进程排障时才固定填写 |
| `FINANCIAL_SINGLE_WRITER_LEASE_FILE` | 跨进程金融写租约文件 | 同一账本必须共享同一路径；由发布流程管理 |
| `FINANCIAL_SINGLE_WRITER_LEASE_MS` | 金融租约有效期毫秒数 | 心跳失联后等待租约释放的时间 |
| `FINANCIAL_SINGLE_WRITER_HEARTBEAT_MS` | 金融租约续租频率 | 必须小于租约有效期的一半 |
| `PAYMENT_RECONCILIATION_ENABLED` | 启用支付/退款后台自动对账 | 真实支付必须开启；模拟支付关闭 |
| `PAYMENT_RECONCILIATION_INTERVAL_MS` | 扫描待确认支付的基础间隔 | 影响后台对账频率 |
| `PAYMENT_RECONCILIATION_INITIAL_DELAY_MS` | 首次查询渠道前的等待时间 | 避免渠道尚未落单时过早查询 |
| `PAYMENT_RECONCILIATION_MAX_DELAY_MS` | 连续待确认时的最大退避 | 必须大于等于首次等待时间 |
| `PAYMENT_RECONCILIATION_BATCH_SIZE` | 每轮最多核对的支付/退款数量 | 防止单轮占用过多资源 |
| `PAYMENT_RECONCILIATION_ALERT_AFTER_ATTEMPTS` | 连续多少次无终态后生成告警 | 只生成一次人工核对告警 |
| `PAYMENT_RECONCILIATION_USER_REQUEST_COOLDOWN_MS` | 用户重复申请核对的最短间隔 | 防止高频触发后台工作 |
| `PAYMENT_NOT_FOUND_CONFIRMATIONS` | 连续多少次“订单不存在”才确认结论 | 防止单次渠道查询误判 |
| `PAYMENT_NOT_FOUND_GRACE_SECONDS` | 新支付单查询不到时的宽限时间 | 宽限内继续等待渠道落单 |
| `PAYMENT_PAYER_IDENTITY_TTL_SECONDS` | 临时付款身份句柄有效期 | 过期后客户端必须重新申请 |
| `PAYMENT_PAYER_IDENTITY_HANDLE_CAPACITY` | 进程内付款身份句柄容量 | 限制内存占用和滥用 |
| `WECHAT_PAY_APP_ID` | 微信支付应用编号 | 敏感配置，必须与小程序主体匹配 |
| `WECHAT_MINI_APP_SECRET` | 微信小程序 AppSecret | 高敏感配置，只能由密钥管理器注入 |
| `WECHAT_MINI_LOGIN_URL` | 微信登录换取会话接口 | 使用微信官方 HTTPS 地址 |
| `WECHAT_PAY_MCH_ID` | 微信支付商户号 | 与商户证书和 App ID 配套 |
| `WECHAT_PAY_API_BASE_URL` | 微信支付 API 根地址 | 使用微信支付官方 HTTPS 地址 |
| `WECHAT_PAY_NOTIFY_URL` | 微信支付结果通知地址 | 必须是公网 HTTPS 且指向当前实例入口 |
| `WECHAT_PAY_REFUND_NOTIFY_URL` | 微信退款结果通知地址 | 必须是公网 HTTPS |
| `WECHAT_PAY_API_V3_KEY` | 微信支付 API v3 密钥 | 高敏感配置，不得回显 |
| `WECHAT_PAY_MERCHANT_PRIVATE_KEY` | 微信商户私钥 | 高敏感配置，保持原始密钥格式 |
| `WECHAT_PAY_MERCHANT_CERT_SERIAL_NO` | 微信商户证书序列号 | 必须与商户私钥对应 |
| `WECHAT_PAY_PLATFORM_CERT_SERIAL_NO` | 微信平台证书序列号 | 用于验证平台回包和通知 |
| `WECHAT_PAY_PLATFORM_PUBLIC_KEY` | 微信平台公钥或证书公钥 | 用于验签，必须来自官方渠道 |
| `ALIPAY_APP_ID` | 支付宝应用编号 | 与签名密钥及应用配置匹配 |
| `ALIPAY_GATEWAY_URL` | 支付宝网关地址 | 使用支付宝官方 HTTPS 网关 |
| `ALIPAY_NOTIFY_URL` | 支付宝异步通知地址 | 必须是公网 HTTPS |
| `ALIPAY_SELLER_ID` | 支付宝收款方编号 | 与签约主体一致 |
| `ALIPAY_APP_PRIVATE_KEY` | 支付宝应用私钥 | 高敏感配置，不得回显 |
| `ALIPAY_PUBLIC_KEY` | 支付宝平台公钥 | 用于验证支付宝通知签名 |

## 九、验证码服务

| 配置键 | 作用 | 使用与修改边界 |
| --- | --- | --- |
| `VERIFICATION_CODE_PROVIDER` | 选择本地模拟或阿里云 PNVS 短信主通道 | 正式实机固定使用 `aliyun_pnvs`；人工签发码不在这里切换 |
| `VERIFICATION_CODE_PREVIEW_ENABLED` | 是否把模拟验证码放进接口响应 | 仅本机模拟联调；正式实机隐藏并强制关闭 |
| `ALLOW_DEFAULT_BACKOFFICE_LOGIN` | 是否允许仍使用默认密码的后台账号登录 | 仅初始化联调；正式实机隐藏并关闭 |
| `PUBLIC_ADMIN_REGISTRATION_ENABLED` | 是否允许公开注册申请管理员身份 | 仅隔离演练；正式管理员必须从后台建立 |
| `ALIYUN_PNVS_ACCESS_KEY_ID` | 阿里云号码认证最小权限 RAM AccessKey ID | 敏感项，只由服务商维护 |
| `ALIYUN_PNVS_ACCESS_KEY_SECRET` | 上述 AccessKey 的 Secret | 高敏感项，只能安全注入，不得回显 |
| `ALIYUN_PNVS_REGION_ID` | PNVS 地域 | 通常按阿里云控制台开通地域填写 |
| `ALIYUN_PNVS_ENDPOINT` | PNVS 官方接口主机 | 使用阿里云官方 HTTPS Endpoint |
| `ALIYUN_PNVS_SIGN_NAME` | 已审核通过的系统签名 | 必须与阿里云控制台一致 |
| `ALIYUN_PNVS_TEMPLATE_CODE` | 已审核通过的验证码模板编号 | 模板应包含验证码占位符 |
| `ALIYUN_PNVS_SCHEME_NAME_APP_LOGIN` | App/小程序登录专用方案名 | 发送与核验必须使用同一方案；可留空使用默认方案 |
| `ALIYUN_PNVS_SCHEME_NAME_REGISTER` | 用户注册专用方案名 | 与登录、重置用途隔离 |
| `ALIYUN_PNVS_SCHEME_NAME_GENERAL` | 通用登录或其他验证方案名 | 只用于 `general` 用途 |
| `ALIYUN_PNVS_SCHEME_NAME_PASSWORD_RESET` | 后台本人密码重置专用方案名 | 只用于 `password-reset` 用途 |

人工签发码不保存全局固定验证码，也不会替代正常短信主通道。实例管理员只能为当前实例中已存在且启用的账号签发 6 位验证码；每个码绑定目标账号、用途、有效期、失败次数和单次消费状态，可随时撤销。长期测试应选择允许的有效期，而不是改成永久通用码。

## 十、正式预约制实例的推荐组合

| 项目 | 推荐状态 |
| --- | --- |
| 服务商平台 | 正式服务商平台 |
| 实例服务类型 | 正式服务 |
| 数据平面 | `live` |
| 预约取货 | 开启 |
| 支付模式 | `disabled`，不创建新的支付单 |
| 验证方式 | 后台签发一次性人工码，或阿里云 PNVS |
| 柜机接入 | 未录入真实柜机前为 `disabled`；接入后为 `real` |
| 地图服务 | 使用已审核和受限域名的高德 Web 配置 |
| 大模型服务 | 可选；未配置时明确显示不可用，不伪造正式结果 |
| 默认密码、验证码预览、公开管理员注册、未签名回调 | 全部关闭 |

## 十一、修改配置的安全顺序

1. 先确认当前实例、实例服务类型和数据平面。
2. 只修改当前业务确实需要的字段，不顺带调整运行路径或安全门禁。
3. 敏感配置通过服务商后台或既有密钥管理方式输入，不粘贴到文档和聊天。
4. 保存后查看“保存即生效”或“重启后生效”标记。
5. 需要重启时，先确认没有未保存项，再使用当前实例的受控重启入口。
6. 重启后复核健康接口、后台登录、App 登录、预约和当前实例柜机可见范围。
7. 任何结果不确定时停止重复提交，先查看操作日志和系统审计。
