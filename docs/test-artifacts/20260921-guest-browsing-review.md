## 变更与范围

原版本的启动页、底部栏目及柜机详情在没有会话时跳转登录，首次进入无法了解服务、浏览物资。现改为游客可浏览服务介绍、柜机位置、物资和可用库存；点击个人领取权益、记录或账户的登录按钮后才进入登录流程。

- 首次进入、已退出登录、登录凭证失效或资格资料尚未完成时，均允许浏览公开服务。
- 记录、我的展示可取消的自主登录入口；登录、资料填写和审核状态页均有继续浏览入口。
- 柜机查询入口登录后仍为查询模式，现场扫码来源则保留原柜机目标；取消登录清除待办目标，防止下次登录误跳转。
- 新增 `GET /api/public/devices`、`GET /api/public/devices/:deviceCode`，按受信请求域名限定实例，只返回公开字段，禁止缓存。
- 游客查询使用原有可用库存计算，保留商品停用、负库存、预约占用和保质期策略。查询不会同步映翰通、生成订单、开门或改写账本。
- 原领取资格、实际领取才消耗权益、开门认证和私人数据接口未放宽。
