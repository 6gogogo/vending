# 业务链路审计测试矩阵

日期：2026-06-02

## 执行原则

- 以本地最新代码为准，先本地验证，不直接操作公网生产代码。
- 同时扮演程序提供商、管理员、商家、用户四种权限视角，其中程序提供商用于验证最高权限和权限下发边界。
- 客服电话只作为柜机异常联系入口，不作为不会操作的兜底说明。
- 每条链路同时检查接口行为、页面引导、权限边界和异常提示。

## 管理员 / 程序提供商链路

| 编号 | 场景 | 操作 | 预期 |
| --- | --- | --- | --- |
| A01 | 程序提供商登录 | 使用 `super/super123` 登录后台 | 可进入全局后台，会话可恢复 |
| A02 | 创建管理员人员 | 新增管理员用户，绑定手机号、区域、状态 | 人员列表出现记录，状态为可用 |
| A03 | 开通后台账号 | 给管理员开通后台登录名和密码 | 新账号可登录后台 |
| A04 | 权限模板 | 选择管理员模板并增减权限 | 只能从当前账号拥有权限中下发 |
| A05 | 越权下发 | 管理员尝试给他人授予自己没有的权限 | 后端拒绝，前端不能表现为成功 |
| A06 | 服务商账号边界 | 普通管理员尝试创建程序提供商账号 | 后端拒绝 |
| A07 | 预约设置 | 配置是否允许预约、保留分钟数、超时次数 | 小程序读取到一致设置 |
| A08 | 领取策略 | 创建当前时段、指定货品、指定用户的领取策略 | 用户端额度同步出现 |
| A09 | 区域配置 | 新增/修改区域 | 后台可保存，注册/人员配置可引用 |
| A10 | 设备配置 | 新增/修改/查看柜机、位置、状态 | 后台设备详情和移动端柜机列表一致 |
| A11 | 货品配置 | 新增分类、货品、上下架/阈值/批次 | 货品总览和柜机货品查询一致 |
| A12 | 仓库调配 | 仓库向柜机调拨、盘点修正 | 库存流水、货品总览、仓库页同步 |
| A13 | 审核用户注册 | 用户提交申请后审核通过/驳回 | 小程序审核状态变化正确 |
| A14 | 审核商家注册 | 商家提交申请后审核通过/驳回 | 商家端可登录或看到驳回原因 |
| A15 | 数据查看 | 查看订单、预约、补货、领取、异常反馈、日志 | 数据可追踪到具体人员、柜机、货品 |
| A16 | 异常处理 | 处理用户/商家反馈任务 | 反馈状态变更，用户端可收到处理状态 |

## 商家链路

| 编号 | 场景 | 操作 | 预期 |
| --- | --- | --- | --- |
| M01 | 商家注册 | 从小程序提交商家身份资料 | 进入待审核，不直接获得权限 |
| M02 | 商家登录 | 审核通过后用手机号验证码登录 | 进入商家工作台 |
| M03 | 柜机查看 | 查看可操作柜机和状态 | 只能看到允许访问的柜机信息 |
| M04 | 常用商品 | 新增、修改、选择常用商品 | 模板保存成功，重复/缺项有提示 |
| M05 | 补货开柜 | 选择柜机并声明有商品入柜 | 创建补货开柜事件 |
| M06 | 补货登记 | 提交商品、数量、生产日期、批次 | 生成批次、库存移动、追踪记录 |
| M07 | 非法补货 | 未确认明细、数量为 0、缺生产日期 | 被前后端拦截 |
| M08 | 异常上报 | 低库存、柜机异常、服务问题反馈 | 后台形成待处理任务 |
| M09 | 去向追踪 | 查看自己的补货批次和消耗去向 | 不能看到无关商家的敏感数据 |
| M10 | 越权访问 | 商家访问管理员人员、全量日志、系统设置 | 被拒绝或页面不可见 |

## 用户链路

| 编号 | 场景 | 操作 | 预期 |
| --- | --- | --- | --- |
| U01 | 首次打开 | 进入小程序入口 | 能理解登录、注册、反馈、指引的下一步 |
| U02 | 注册申请 | 提交手机号、验证码、身份、姓名、区域 | 进入待审核 |
| U03 | 审核中登录 | 使用待审核手机号登录 | 进入审核状态，不误导重复注册 |
| U04 | 审核通过登录 | 管理员审核后重新登录 | 进入用户首页 |
| U05 | 今日额度 | 查看额度、可领取时段、可领取物资 | 与后台策略一致 |
| U06 | 附近柜机 | 查看地图/列表、库存、开放状态 | 信息足够选择柜机 |
| U07 | 提前预约 | 选择柜机和货品预约 | 库存足够时成功，库存不足时拒绝 |
| U08 | 取消预约 | 用户取消未履约预约 | 状态更新，库存释放 |
| U09 | 预约开柜 | 预约后开柜领取 | 事件创建、柜门状态、结算链路可完成 |
| U10 | 现场领取 | 不预约直接选择货品开柜 | 额度、库存、支付预览正确 |
| U11 | 额度不足 | 超出免费额度继续取货 | 预结算提示需支付或被规则拦截 |
| U12 | 无库存 | 选择无库存货品 | 不允许预约/开柜 |
| U13 | 柜机异常 | 开门失败、门未关、设备破损反馈 | 引导提交反馈；柜机异常页可联系客服电话 |
| U14 | 资格异常 | 非本人手机号、未审核、超出时段 | 被拒绝且说明清楚 |
| U15 | 领取成功 | 结算回调完成 | 记录页出现领取流水，预约变为完成 |
| U16 | 领取失败恢复 | 开柜失败、结算异常、支付未完成 | 结果页提供可执行恢复路径 |

## 横向边界测试

| 编号 | 场景 | 操作 | 预期 |
| --- | --- | --- | --- |
| E01 | 未登录访问 | 访问预约、领取记录、后台数据接口 | 返回未登录或跳转登录 |
| E02 | 角色越权 | 用户/商家访问管理员接口 | 拒绝访问 |
| E03 | 权限越权 | 有后台账号但缺具体权限 | 拒绝访问，不显示可操作入口 |
| E04 | 重复提交 | 注册、预约、补货、反馈连续点击 | 不生成重复脏数据或有明确拦截 |
| E05 | 错误输入 | 空姓名、错误手机号、数量 0、非法小时 | 前后端均拦截 |
| E06 | 网络失败 | API 暂不可用时页面加载 | 出现可理解的失败/重试状态 |
| E07 | 刷新恢复 | 登录后刷新页面、重新打开小程序 | 会话恢复，角色路由正确 |
| E08 | 空数据 | 无柜机、无库存、无记录、无待办 | 空状态文案可理解且可继续操作 |
| E09 | 回调安全 | 伪造柜机回调 | 签名/来源校验拦截，不能写入正式流水 |
| E10 | 数据一致性 | 领取、补货、调拨后跨页面查看 | 订单、日志、库存、批次一致 |
