## 发现并修复的问题

| 问题 | 修复后的行为 |
| --- | --- |
| 搜索或手机导航点击当前页，URL 不变导致浮层残留 | 点击入口即收起浮层，重复导航也正常返回内容 |
| 设置未保存时，搜索框遮住离开确认 | 搜索先关闭，继续编辑、不保存、保存并离开均可接管；确认打开时 Ctrl+K 不叠加搜索 |
| 退出账户后仍被草稿留在旧页面 | 会话撤销或轮换后直接离开；退出失败仍清理本机会话，不自动保存草稿 |
| 连续导航覆盖确认 Promise，旧导航可能一直等待 | 多次导航共用一次决定，卸载时释放等待 |
| “保存并配置每日物资”停在人员概况 | 成功后直达该人员 `?section=rules`；保存中防重复，失败保留草稿 |
| 只读页面附带无权限的柜机请求 | 人员、货品和仓库按会话权限加载辅助数据，主列表不再被该请求拖垮 |
| 页面与搜索分区定义分散，初始化指引无法检索 | 工作台、人员、货品和仓库共用分区定义，页面单独补实时角标 |
| 离开页面后，迟到响应重新启动后台轮询 | 工作台与柜机页共用轮询生命周期；隐藏暂停、返回刷新、卸载停止；慢请求不叠加 |
| 快速切换对象，旧响应可能覆盖当前资料或盘点库存 | 只允许当前请求写回，换对象立即清空旧明细，旧成功和失败响应均不能覆盖当前状态 |
| 人员详情失败没有明确恢复入口 | 显示具体错误与重新加载按钮，失败后不再显示“加载中” |
| 货品调拨忽略 `warning_only`，提醒模式也被日期阻止 | 服从返回的保质期模式；严格模式仍阻止到期批次，服务端继续独立校验 |

这些问题包含重构交互回归和本轮发现的既有异步问题。后端权限模型、数据库结构、外部设备协议未改变。
