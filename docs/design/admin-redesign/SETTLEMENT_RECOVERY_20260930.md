# 结算失败自动恢复与历史订单处理

## 行为与边界

- 已验签且通过订单绑定、金额和数量校验的结算回调，发现货品目录缺项时，立即同步对应柜机货品并重新结算。
- 同步、结算或平台完结回写失败，持久化待办及下次执行时间。十分钟后再同步、再结算，最多追加三次重试（包含首次共四次）。调度按分钟检查，实际执行不早于到期时间。
- 待办直接显示进度、下次时间、剩余次数；达到上限后停止自动重试并保留人工处理提醒。只有本地结算及平台回写都成功才自动关闭。
- 平台重复回调不能重置次数或提前重试；重启保留计数和截止时间。已有库存记账不重复扣减，零元平台回写沿用交易号；旧的一分钟完结任务不绕过恢复任务的间隔或次数上限。
- 恢复数据只保存白名单业务字段，并关联已验签的原始回调记录；待恢复期间保护该回调不被日志容量清理。恢复不伪造签名、不把截图识别编码当作事件编号。
