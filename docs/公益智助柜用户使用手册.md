# 公益智助柜用户使用手册

本手册供“小柜大爱”实例内的使用者查阅。请先按身份找到自己的入口，再按照页面名称完成操作。不要在聊天、截图或公开工单中发送密码、手机号和一次性验证码。

## 1. 开始使用

### 1.1 选择入口

| 使用者 | 登录入口 | 可以完成的工作 |
| --- | --- | --- |
| 实例管理员 | [电脑后台](https://vending.5gogogo.top/login) | 管理人员、货品、柜机、库存、预约规则和操作记录。 |
| 商户 | [电脑后台](https://vending.5gogogo.top/login) | 查看商家工作台、可补货清单、本人入柜记录和已分配柜机。 |
| 补货员 | [电脑后台](https://vending.5gogogo.top/login) | 查看已分配柜机的状态、货门和可见库存。 |
| App 用户 | [移动端](https://vending.5gogogo.top/mobile/) | 使用一次性验证码登录、预约物资并查看领取状态。 |

带端口入口 [http://5gogogo.top:5795/](http://5gogogo.top:5795/) 会自动转到 HTTPS 主站。登录和业务操作都在 HTTPS 页面完成。

![电脑后台登录页](assets/backoffice-login-public-1280x720-20260729.png)

### 1.2 登录前确认

- 实例管理员需要已经开通的后台账号。
- 商户和补货员需要实例管理员开通后台账号，并分配可查看的柜机。
- App 用户需要先完成建档和启用，再取得一条当前有效的一次性验证码。
- 当前实例采用预约领取，不需要配置或完成支付。

## 2. 实例管理员

### 2.1 第一次登录

1. 打开电脑后台，输入账号和密码。
2. 登录后确认左侧显示“实例管理员”。
3. 打开“运营总览”，查看人员、柜机、库存和预约是否有异常提示。
4. 打开“系统设置”，确认预约取货、额度规则和 App 登录方式。
5. 至少保留两名可登录的实例管理员，避免唯一管理员忘记密码后无人签发找回验证码。

完成后，后台应显示当前实例的业务菜单，不应出现其他实例的数据。

### 2.2 设置预约领取

打开“系统设置 → 领取与服务设置”，找到“实例设置”：

1. 开启“预约取货”。
2. “额度差额归属”一般选择“自动”；只有业务制度明确要求时才选择其他日期方式。
3. “App 登录验证方式”选择“手动验证码”。
4. 保存设置，并重新进入页面确认选项已经生效。

预约取货开启后，App 用户先预约再领取，页面不会要求支付。若 App 出现付款步骤，请先暂停使用并重新检查本页设置。

![正式实例的领取与服务设置](assets/backoffice-instance-settings-live-1440x900-20260730.jpg)

### 2.3 建档、启用和分配权限

1. 打开“人员管理”。
2. 新建人员，或打开待审核的申请。
3. 核对姓名、手机号和申请身份。
4. 选择实例管理员、商户、补货员或普通用户身份。
5. 需要登录电脑后台时，为该人员开通后台账号。
6. 商户和补货员必须分配柜机；未分配的柜机不会出现在其列表中。
7. 启用人员后，再检查账号状态和柜机分配结果。

普通用户只使用 App，不需要电脑后台账号。人工验证码只能发给已经建档并启用的用户，不能代替建档。

### 2.4 管理货品、库存和柜机

1. 在“货品总览”建立或维护货品资料和图片。
2. 在“本地仓库”核对可用库存和批次。
3. 在“柜机监控”查看柜机在线状态、货门和当前库存。
4. 新增或修改柜机后，进入柜机详情检查保存结果。
5. 在“日志总览”核对关键操作的时间、对象和结果。

尚未接入真实柜机时，柜机列表或可预约库存可能为空。此时 App 可以登录和查看服务状态，但不能完成真实到柜领取。

### 2.5 签发 App 登录验证码

1. 在“人员管理”中找到已经启用的 App 用户。
2. 打开“人工验证码”。
3. 用途选择“APP / 小程序登录”。
4. 输入本次使用的 6 位验证码，并设置有效期。
5. 签发后，通过私下、安全的方式交给本人。
6. 用户登录后检查该验证码状态；已经使用的验证码不能再次登录。

验证码过期、被撤销、输错达到上限或已经使用后，需要重新签发。不要多人共用同一条验证码。

### 2.6 修改或找回后台密码

知道当前密码时：

1. 登录电脑后台。
2. 在左侧选择“修改密码”。
3. 输入当前密码和两次新密码。
4. 保存后使用新密码重新登录。

忘记密码时：

1. 在后台登录页选择“忘记密码”。
2. 输入后台账号和人员资料中绑定的手机号。
3. 当前为人工验证码模式，请另一名实例管理员签发用途为“后台密码重置”的验证码。
4. 输入验证码和两次新密码，选择“验证并重置密码”。
5. 重置成功后返回登录页。原有登录会话会立即失效。

如果当前实例只有一名管理员，且无法取得找回验证码，请联系技术支持。初始 admin 账号的新密码不少于 6 位；其他后台账号的新密码不少于 8 位。

## 3. 商户和补货员

### 3.1 商户

1. 使用实例管理员开通的后台账号登录。
2. 打开“商家工作台”，查看可补货货品模板和本人最近入柜记录。
3. 打开“柜机监控”，只查看分配给自己的柜机。
4. 进入柜机详情，核对柜机状态、货门和可见库存。
5. 现场补货完成后，由实例管理员登记或复核对应补货记录。

当前商家工作台以查询和核对为主。页面没有显示的任务处理、柜机编辑、远程开门和完整日志由实例管理员处理。

### 3.2 补货员

1. 使用实例管理员开通的后台账号登录。
2. 打开“柜机监控”，确认目标柜机已经分配给自己。
3. 进入柜机详情，核对柜机编号、货门和可见库存。
4. 按现场安排完成补货或巡检。
5. 将异常柜门、库存差异和现场情况反馈给实例管理员，由管理员登记和处理。

看不到未分配柜机属于正常权限限制。不要借用他人账号，也不要尝试处理页面没有提供的管理功能。

## 4. App 用户

### 4.1 第一次使用

首次使用前，请联系当前实例管理员完成资料建档、审核和启用。当前人工验证码模式不会发送短信，也不会自动创建账号。

![App 身份识别页](assets/app-public-login-390x844-20260729.png)

### 4.2 使用一次性验证码登录

1. 打开移动端，选择“登录 / 身份识别”。
2. 输入本人手机号。
3. 输入实例管理员交付的 6 位一次性验证码。
4. 阅读页面提示并勾选免责声明。
5. 选择登录。

登录成功后，首页会显示当前服务状态、可用柜机和预约入口。验证码使用一次后立即失效。

![App 人工验证码登录页](assets/app-public-manual-login-390x844-20260729.png)

### 4.3 预约物资

1. 在首页查看当天是否开放领取。
2. 选择在线柜机。
3. 选择可预约物资和数量。
4. 核对柜机、物资、数量和保留时间。
5. 提交预约，并在“当前预约”确认状态。

没有在线柜机、没有可用库存或不在开放时段时，页面不会提供可提交的预约。

### 4.4 到柜领取

1. 在预约有效期内到达页面显示的柜机。
2. 打开“当前预约”，再次核对柜机和物资。
3. 按页面提示完成距离确认和开柜确认。
4. 取出物资并关好柜门。
5. 等待页面显示最终结果，不要连续重复开柜。

预约领取不要求付款。预约超时、柜机离线或开柜结果长时间未确认时，请保留当前页面并联系实例管理员。

## 5. 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 实例管理员忘记后台密码 | 在登录页选择“忘记密码”，由另一名实例管理员签发找回验证码；没有其他管理员时联系技术支持。 |
| App 用户无法登录 | 确认账号已建档并启用，手机号属于当前实例，验证码未过期、未撤销且未使用。 |
| 页面没有发送短信 | 当前采用人工验证码，由实例管理员签发，不会发送短信。 |
| 商户或补货员看不到柜机 | 请实例管理员检查角色、账号状态和柜机分配。 |
| 商户看不到补货按钮 | 当前商家工作台用于查看模板和本人记录，补货登记由实例管理员处理。 |
| App 没有可预约物资 | 请管理员检查柜机在线状态、货品、库存、服务时段和预约设置。 |
| App 出现付款步骤 | 暂停操作，并请管理员检查是否已经开启预约取货。 |
| 开柜后页面没有立即确认 | 停留在结果页等待系统查询，不要再次开柜；仍无结果时联系实例管理员。 |
| 看到“无权访问” | 返回当前身份可见的菜单；需要扩大权限时联系实例管理员。 |
