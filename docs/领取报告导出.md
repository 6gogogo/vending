# 后台领取报告导出

入口：客户实例后台 → 数据分析 →「数据导出」页签（与每日运营、服务人次同级）。默认最近 7 天，也可自选包含起止日期的时间段，单次最多 366 天、5 万条明细。

默认勾选「领取明细」「领取概览」，明细在第一个工作表，字段为领取日期、领取人、领取时间、派发出的物资、领取数量。日期从旧到新，同一天时间从早到晚；按天交替底色，保留格线和加宽的左侧留白。

以下选项默认不勾选：

- 柜机名称 / 编号、社区 / 街道、脱敏手机号：增加到领取明细。
- 按人员汇总：独立工作表，含领取天数、人次、件数及物资。
- 按柜机汇总：独立工作表，含服务人数、人次、件数及物资。

不提供关门时间、结算时间或领取小时列。未勾选的明细字段不会作为隐藏列写入文件；手机号只输出脱敏值。

## 统计口径与边界

- 领取时间采用原事件首次成功开门回调的接收时间，沿用业务时区及业务日切换配置（默认 UTC+8、04:00）。不以迟到的结算时间替代。
- 仅统计当前实例内公益领取人员的已结算 / 已退回取货事件；排除失败、补货、盘点、空取货。
- 同一事件同一货品合成一行，领取量减去退回量；全部退回后不计入净派发。同一事件领取多种物资仍只算一次人次。
- 无可信开门回调的事件不编造时间、不纳入明细；若库存流水落在所选范围，会在默认明细 / 概览中提示遗漏笔数。历史回调已被清理时，导出范围不代表完整历史，需核对原始记录。
- 该接口只读取数据，不同步平台、不发起结算、不改变库存。
- 必须同时具备 `analytics:data-monitor:view` 和 `operation-logs:export` 权限，实例范围来自服务端验证的会话，忽略客户端自报实例。
